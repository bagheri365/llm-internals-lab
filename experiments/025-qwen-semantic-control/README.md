# Experiment 025
Run `python experiments/025-qwen-semantic-control/run.py` for pilot (40 matched, 50 generation records), or add `--full --output results/experiment-025-semantic-control-full.jsonl` for 80 matched and 90 generation records. Uses pinned HF model, not Ollama. No dependencies on prior runners. Greedy generation, 64 new tokens by default. Decode mode skips prefill; matched_once edits only first prediction after forced continuation. Dose zero uses no hook. Score complete responses manually against expected answers, with ambiguous/truncated responses separate; do not classify mere company mentions as attribution. Compare paired baseline-correct controls and report denominators by category and dose. English Open/Alibaba token probabilities are diagnostics, not valid multilingual semantic scores. Forced continuations can prime answers; natural generation is the primary semantic endpoint. Small selected sample, FP16, no random-coordinate controls or independent replication. No weight changes.
